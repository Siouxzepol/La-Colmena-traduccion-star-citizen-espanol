# Star Citizen — traducción al español de España

Traducción comunitaria no oficial para Star Citizen. El archivo `global.ini` está preparado para la carpeta de localización `spanish_(spain)`.

## Instalación

1. Cierra Star Citizen.
2. Haz una copia de seguridad de `LIVE/data/Localization/spanish_(spain)/global.ini`.
3. Sustituye ese archivo por el `global.ini` de este repositorio.
4. Inicia el juego y selecciona español de España.

Las actualizaciones del juego pueden sobrescribir el archivo o añadir cadenas nuevas; revisa este repositorio después de cada actualización.
